01 / Case study

A due diligence report platform, built solo

A web platform that produces due diligence reports on people and companies. It collects data from 38 source modules in parallel and assembles the results into one report. The client uses it in production, internally. I built the backend, the API and the web app on my own in about three months.

Isolation

Each source module runs on its own Redis queue, split by load, so a slow source doesn't hold up the rest of the report.

Testing

About 1,700 automated tests, and CI runs on every pull request.

Delivery

An API and a web app in React and TypeScript, used internally by the client in production.

03 / How I work

Start small, in writing

  1. 01

    You describe the problem by email.

    Tell me what data you need, where it comes from and how often. A few paragraphs is enough.

  2. 02

    We agree on a small fixed-scope pilot.

    One clear deliverable, scope agreed in writing before I start, so you can judge the work before committing to more.

  3. 03

    I work async and keep you updated in writing.

    You get regular written updates on what's done, what's next and any blockers, with no need to schedule meetings.

  4. 04

    Optional: monthly maintenance.

    Websites and data sources change, and scrapers break when they do. If you want, I keep things running after delivery.

Time zone

I'm on UTC-3. That overlaps with the full US business day and with European afternoons.
